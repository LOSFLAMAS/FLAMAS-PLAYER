Flamas Player sirve para buscar servidores de juegos hechos con **Flamas Engine** y entrar a jugar.

- Solo puedes jugar los juegos que ya est&aacute;n en un servidor.
- El juego se baja del servidor la primera vez que entras y se guarda **cifrado**: solo Flamas Player lo puede abrir.
- **Se actualiza solo**: cada vez que lo abres revisa si hay una versi&oacute;n nueva y, si la hay, la baja y se vuelve a abrir.

## C&oacute;mo instalarlo

1. Haz clic en el bot&oacute;n **DESCARGAR** de arriba (siempre baja la versi&oacute;n m&aacute;s reciente).
2. Descomprime `FlamasPlayer.zip`: queda una carpeta `Flamas_Player`.
3. Abre `Flamas_Player\FlamasPlayer.exe`.

Para tenerlo en el men&uacute; Inicio y el escritorio, usa la opci&oacute;n de instalar dentro del programa.
